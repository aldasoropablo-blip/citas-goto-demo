IVR con GoTo para agendar visitas por propiedad

Inmobiliaria Carvalho combina una agenda web externa con un flujo telefónico GoTo para solicitar visitas, transferir llamadas y acompañar al asesor sin mover la lógica del folio fuera de la app.

Cómo funciona el flujo

GoTo se conectará al flujo como capa de atención telefónica, mientras la app externa conserva la lógica de cita y folio.

1

Agenda web

El cliente puede agendar desde el formulario web. Si agenda por web, la app genera un folio y muestra confirmación con WhatsApp.

2

Agenda desde IVR

También puede llamar al IVR para solicitar agenda de una propiedad. Si elige una propiedad disponible, un asesor puede continuar el proceso.

3

Agenda llena

Si elige una propiedad con agenda llena, el IVR lo indica con una respuesta normal y sugiere elegir otra propiedad o hablar con un asesor.

4

Folio externo

La cita y el folio viven temporalmente en la app externa para esta demo. GoTo no guarda el folio ni la cita.

5

Canales GoTo

GoTo se usa para IVR, llamadas, transferencia a asesor y bandeja de WhatsApp. El folio se usa como referencia durante la conversación.

6

Panel del asesor

El asesor usa el panel externo para registrar, confirmar, reagendar o cancelar la cita usando el folio.
